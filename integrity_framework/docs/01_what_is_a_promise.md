# 01 · 什么算承诺、什么不算 · What Counts as a Promise

> 这是 [METHODOLOGY.md §3.1](../METHODOLOGY.md#31-promise-承诺) 的扩展讨论。如果只读一份,读 METHODOLOGY。

---

## 三条硬门槛

一条文本能被记录为 `Promise`,必须**同时**满足:

1. **公开性** — 不是私下投资者沟通、不是内部备忘
2. **可识别说话人** — 不是 "公司方面"/"知情人士",必须是具体的某人
3. **可量化或可观察的结果** — 不是宏观愿景,必须能被一个具体事件回答 "做到了/没做到"

任何一条不满足,**不**记录。**宁可漏一条,也不要记录无法判定的承诺**。

## 四类常见承诺

### 1. 财务指引(`verification_type: financial_metric`)

✅ 算:
- "FY24 营收同比增长 25%"(具体数字 + 时间窗口)
- "Q3 毛利率维持在 40% 以上"
- "2025 全年自由现金流转正"

❌ 不算:
- "我们对未来增长充满信心"(无数字、无时间)
- "我们将持续优化盈利结构"(无可证伪)
- "公司方面表示利润将改善"(说话人不明)

### 2. 产品发布(`verification_type: product_launch`)

✅ 算:
- "AI Agent 产品 2025 Q1 GA"
- "海外版 App 在 H2 上线印尼市场"

❌ 不算:
- "我们在探索新的产品方向"
- "AI 是我们的长期战略"

### 3. 战略举措(`verification_type: strategic_initiative`)

✅ 算:
- "2025 年内完成对子公司 X 的并购"
- "Q4 关闭 30% 线下门店"

❌ 不算:
- "我们看好行业整合机会"
- "我们将更聚焦核心业务"

### 4. ESG 目标(`verification_type: ESG_target`)

✅ 算:
- "2030 年实现运营碳中和"
- "2027 年女性高管比例达 40%"

❌ 不算:
- "我们承诺成为更负责任的企业"
- "我们重视员工福祉"

## 边界灰区

### "Will" vs "Plan to" vs "Aim to"

英文承诺强度:`will` > `commit` > `plan to` > `aim to` > `hope to`。

中文对应:`承诺` > `将` > `计划` > `争取` > `希望`。

**MVP 当前规则**:`will / 将 / 承诺 / commit / plan / 计划 / target / guidance` 都纳入。`aim / hope / 希望` 不纳入(模糊度太高)。

未来可能加 `confidence_level` 字段做区分。

### 公司方面 vs 具体管理层

> "公司发言人表示明年将扩大产能"

公司发言人 ≠ 具体管理层。倾向**不**记录,除非:
- 来源能 trace 到具体某高管(如电话会 transcript 写明 CFO 在某段说了这话)
- 公司是小型且发言人即创始人本人(此时记 `made_by: <CEO 姓名>`)

### 自愿指引被撤回

> 公司 Q1 给了 FY24 25% 增长指引,Q3 撤回指引,Q4 实际 -2%。

处理:
- 原 promise 仍记录为 `due_by: FY24 end`
- Verdict outcome = `broken`(因为指引在公开,撤回 ≠ 不算数)
- Verdict reasoning 必须解释撤回这件事
- `severity_tag` 不放(撤回不构成 misconduct,但 reasoning 要明确)

### 多次重复同一承诺

> CEO 在 Q1/Q2/Q3/Q4 电话会都重复 "FY24 营收增长 25%"。

处理:**记录为一条 promise**,以最早一次为准(`made_on` = Q1 时间)。后续重申不增加额外 promise,但 verdict reasoning 可以提"多次重申"作为说话人主观信心高的证据。

如果**数字变了**(从 25% → 20% → 15%):**记录为多条 promise**,以体现 guidance 的持续下调。

### 业绩超预期

> 承诺 25%,实际 30%。

`outcome: fulfilled`。框架**不**奖励超预期(METHODOLOGY §4.1),所以不会拉高分数,但 reasoning 可以写"超预期 5pp"作为可被未来引用的事实陈述。

## 不接受的"承诺"

| 文本 | 为什么不算 |
|---|---|
| "管理层有信心实现今年目标" | 无数字、无时间窗口 |
| "我们将持续创新" | 无可证伪 |
| "未来 5-10 年" | 时间窗口太宽,在框架中无法到期 |
| "如果市场环境允许" | 条件性表述,无法判定违背 |
| 内部 OKR 流出 | 不公开,违反公开性原则 |
| 私下投资者电话纪要 | 不公开 |
