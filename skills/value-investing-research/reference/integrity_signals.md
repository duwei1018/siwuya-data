# 管理层诚信信号清单 · Integrity Signals Reference

> 给 Claude 加载用的参考文档。**正面信号 + 负面信号** 各 10 条,辅助 verdict 判定时使用。

**关键原则**:这些不是"打分项",是"调查方向"。最终 verdict 仍然要回到 [`integrity_framework/`](../../../integrity_framework/) 的结构化方法论。

---

## 正面信号 · Positive Signals

### P1. 主动承认错误 + 不甩锅

**例子**:CEO 在电话会中明确说 "我们在 X 决策上判断错了,原因是 ... 后续我们会 ..."

**为什么正面**:多数 CEO 把失败归于"宏观 / 行业 / 黑天鹅"。主动承担 + 给具体改进 = 罕见的诚实信号。

**判断要点**:不只是"道歉",要有具体复盘 + 后续行动。

### P2. 业绩指引保守且持续 beat

**信号**:多季度连续指引下限 + 实际超出 5-10%。

**为什么正面**:管理层不愿"画饼"——是承诺纪律的体现。

**对比反信号**:每季 "miss by 5%"(画饼但完不成)。

### P3. 长期稳定的高管团队 + 平稳交接

**信号**:核心高管平均任期 > 5 年;CEO 交接是 internal promotion + 提前 1+ 年宣布。

**为什么正面**:"火车头不停换 + 仓促交接" 几乎总是诚信问题的预警。

### P4. 主动披露不利消息

**信号**:产品故障 / 客户流失 / 监管调查这些事公司**主动**披露,且早于媒体爆出。

**为什么正面**:被动披露是"不得不",主动披露是"愿意"——区别巨大。

### P5. 创始人长期持有 + 极少减持

**信号**:创始人持股 5 年内减持 < 5%;且每次减持有明确说明 + 提前披露。

**为什么正面**:跟股东利益深度绑定 + 行为透明。

### P6. 简单、清晰、稳定的薪酬结构

**信号**:CEO 薪酬有 60%+ 与 multi-year ROIC / OCF 挂钩;不依赖"调整后 EBITDA"等可操纵指标。

**为什么正面**:错误激励是诚信问题的源头;好激励是好诚信的基础。

### P7. 派息 + 回购理性

**信号**:派息率与现金流匹配(不超过 OCF 的 50% 多);回购在低估时进行(看回购时点的 P/E vs 历史均值)。

**为什么正面**:理性资本配置 = 管理层把股东当真正的股东。

### P8. 关联交易最小化

**信号**:关联交易 / 营收 < 5% 且每笔走 fair-pricing 流程公开披露。

### P9. 一致的会计处理

**信号**:5 年内会计政策无重大变更;每次微调都有清楚解释。

### P10. 投资者沟通的"非脚本"质量

**信号**:电话会 Q&A 中,管理层会被问到细节并能不回避地回答(包括承认"这个数字我现在不掌握,会后跟你 follow up")。

**对比反信号**:每个问题都给"非答非问"的标准式回答。

## 负面信号 · Negative Signals

### N1. 频繁修订过往业绩

**信号**:5 年内 restate financial statements 2 次以上;或多次重大会计政策变更(尤其在审计师变更前后)。

**严重度**:高(可能触发 `severity_tag: financial_misconduct`)

### N2. 审计师出具非标意见

**信号**:审计师出具 qualified / adverse opinion 或 disclaimer of opinion;或拒绝重新签字。

**严重度**:高(应触发 `severity_tag: audit_qualification`)

### N3. 高管在重大事件前减持

**信号**:坏消息(财报暴雷 / 监管调查 / 重大客户流失)宣布前 30 天内,有重大内部人减持。

**严重度**:高(可能涉及内幕交易)

### N4. 关联交易急剧上升

**信号**:关联交易 / 营收 比率从 5% 跳到 15%+;且新关联方解释模糊。

**严重度**:中-高(可能涉及利益输送)

### N5. 频繁换 CFO

**信号**:3 年换 2+ 个 CFO,且新 CFO 来自审计 / 投行 而非业务背景。

**严重度**:中(信号:可能在准备 cleanup,但也可能是治理问题)

### N6. 业绩指引"刚好"达标

**信号**:连续 4+ 季度指引误差 < 1%。

**严重度**:中(过度平滑 = 可能在调利润)

### N7. 一次性 / 非经常项目滥用

**信号**:每年都有大额"非经常性损失",但项目类型相似。

**严重度**:中

### N8. 重大事件回应迟缓

**信号**:监管调查 / 媒体爆雷 24 小时内无任何官方回应,或回应是"暂不评论"。

**严重度**:中

### N9. 投资者关系绝对不透明

**信号**:不开电话会;不接受 1-on-1 沟通;CFO 拒绝回答任何具体数字问题。

**严重度**:中

### N10. CEO 个人争议 / 公开承诺反复违背

**信号**:CEO 在公开演讲 / 社交媒体频繁说大话又不兑现;或有重大个人争议(诉讼 / 监管处罚)。

**严重度**:中(取决于事件严重性)

## 给 Claude 的判定指引

### 当用户给一个 verdict 时,Claude 应该做的

1. **先问 source**:这个 outcome 判断是基于什么公开信息?有 URL 吗?
2. **检查上面正/负面信号清单**:用户描述的现象,是否对应清单中的某一条?
3. **建议 severity_tag**(如果适用):如果用户的 verdict 是 broken,Claude 应该问 "你是否认为这个属于 financial_misconduct / audit_qualification / fraud_admission 之一?如果是,加 severity_tag 会让分数额外 -30"
4. **写出完整 reasoning**:Claude 帮用户把口语化的判断转成 50-100 字的可审计 reasoning,引用具体信号

### 当用户问"这个公司诚信怎么样"时

1. **拒绝直接打分**:"我无法直接给一个公司打分——但我可以帮你建立一份 verdict 列表,然后用 integrity_framework 算"
2. **引导走 walkthrough**:用 `examples/scoring_walkthrough.ipynb` 的流程
3. **强调 caveat**:`counted_verdicts < 5` 时分数没什么意义
