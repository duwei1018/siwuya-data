# 财务危险信号清单 · Financial Red Flags Reference

> 给 Claude 加载用的参考文档。20 个值得警惕的财务信号,按"硬危险/软危险"分类。

**关键原则**:任何一个红旗都**不**是定罪依据,只是触发更深入调查的信号。**3 个以上同时出现**才有资格作为 thesis-changing 证据。

---

## A 类 · 硬危险(任何一个出现都需要立即深查)

### A1. 现金流与利润长期背离

**信号**:营业利润为正但 OCF (经营现金流) 长期为负;或 OCF / 净利 < 0.7 持续 3+ 年。

**为什么是危险**:利润是会计制度产物,可被调节;OCF 不容易调节(应付账款除外)。两者长期背离 = 收入"赚到了但收不回",或者"利润是应收 stuffing 出来的"。

**怎么验证**:看现金流量表 → 经营性应收 / 存货变化是否异常增大。

**A 股 / 港股加分**:特别注意"销售商品收到现金"占营收比重的变化(应该 ≈ 营收 × 1.13 给增值税,显著低于这个比例 → 危险)。

### A2. 应收账款增速 > 营收增速 持续多季度

**信号**:应收账款 / 营收比率持续上升。

**为什么是危险**:典型的"压货 / 关系销售"。客户没真正买,只是答应未来付。

**怎么验证**:5 季度同比看 应收 / 营收 比率,持续上升 = 红灯。

### A3. 存货周转大幅恶化

**信号**:存货周转天数同比大幅延长(>20%)。

**为什么是危险**:产品卖不动 / 渠道压货。

**怎么验证**:计算 存货 / 单季度营业成本 × 90,看 5 季度趋势。

### A4. 商誉占总资产比重过高

**信号**:商誉 / 总资产 > 30%。

**为什么是危险**:大量商誉 = 历史并购定价过高,后续大概率减值。

**怎么验证**:报表"商誉"科目,看占比 + 是否近年大额减值过。

### A5. 频繁换审计师

**信号**:3 年内换过 2 次以上审计师,且伴随审计意见类型变化。

**为什么是危险**:审计师换了通常意味着双方对会计处理有分歧。

**怎么验证**:历年年报"审计师"段。

### A6. 关联交易占比异常高

**信号**:关联交易 / 营收 > 20%(行业均值通常 < 5%)。

**为什么是危险**:关联交易是利润操纵 / 利益输送的常见通道。

**A 股特别**:看大股东占款 / 关联方贷款。

### A7. 高管 / 大股东集中减持

**信号**:多位高管同时减持 + 大股东大幅减持(超过总持股 10%)。

**为什么是危险**:内部人最知道公司真实情况。

**怎么验证**:交易所披露的减持公告。

## B 类 · 软危险(单独不致命,但叠加多个需警惕)

### B1. EBITDA 与净利差距持续扩大

**信号**:EBITDA / 净利 比率从历史 ~2× 涨到 5×+。

**为什么是危险**:折旧摊销在加速消耗,可能资产质量在下降;或财务费用在上升。

### B2. 资本支出 / 折旧 长期大于 1.5

**信号**:CapEx / D&A 长期 > 1.5。

**为什么是危险**:公司在高速扩产,但要看 ROIC 是否同步提升——若 ROIC 同时下降 = 烧钱式扩张。

### B3. 销售费用占比异常高

**信号**:销售费用 / 营收 显著高于行业均值。

**为什么是危险**:产品自身竞争力不足,需要重金推广;或者渠道返利过高。

### B4. 研发费用突然大幅波动

**信号**:研发费用 / 营收 同比波动 > 30%。

**为什么是危险**:研发是会计调节空间(资本化 vs 费用化)。突然变化 = 可能在调利润。

### B5. 应付账款异常增长

**信号**:应付账款 / 营业成本 持续上升。

**为什么是危险**:在压供应商,可能是流动性紧张的信号(掩盖资金链问题)。

### B6. 长短期借款结构突变

**信号**:短期借款占总借款比重突然上升。

**为什么是危险**:可能是长期信贷被收紧,公司只能借短期续命。

### B7. "其他"科目占比异常高

**信号**:利润表 / 资产负债表的"其他流动资产 / 其他营业收入 / 其他营业支出"占比 > 5% 且无说明。

**为什么是危险**:藏污纳垢的常见通道。

### B8. 经营租赁突然大幅增加

**信号**:经营租赁付款承诺(表外)同比剧增。

**为什么是危险**:把负债 hide 在表外。新会计准则 IFRS 16 / ASC 842 已大幅改善这个问题,但仍要看附注。

### B9. 业绩长期"踩线"达标

**信号**:每季度都"刚好"达成指引下限,误差 < 1%。

**为什么是危险**:真实经营不可能每次都"刚好"——大概率被会计调节平滑了。

### B10. 一次性损失 / 非经常项异常频繁

**信号**:每年都有"一次性"重大损失,但年年都"一次性"。

**为什么是危险**:把经常性问题伪装成一次性。

## C 类 · 治理类信号

### C1. 独立董事比例 / 任期问题

**信号**:独董人数 < 1/3 董事会;或独董任期超过 6 年(独立性存疑)。

### C2. 关键岗位长期由家族成员把持(非创始人时期)

**信号**:CEO / CFO / 审计委员会主席同一家族。

### C3. 公司经常发"暖话"安抚投资者但缺少行动

**信号**:每次电话会都说"我们重视股东回报",但分红率 < 20% 且无回购。

### C4. 投资者关系不透明

**信号**:不开电话会 / 不接受分析师覆盖 / 不回应媒体询问。

## 给 Claude 的指引

当用户分析公司财报时:

1. **不要逐个红旗机械检查**——按行业 priors 选最相关的 5-7 个
2. **3+ 红旗叠加才是 thesis-changing 信号**——单一红旗是"调查触发器"不是"判罪依据"
3. **A 股 vs 港股 vs 美股要分开**——同一个数字含义不同(如关联交易比重)
4. **永远引用具体报表段落 + URL**——"应收账款增长" 这种说法要给具体数字 + 期间
